# laba2
Задача 1 - Обратный порядок списка
Дана задача: Заполнить список L исходными числами и вывести элементы списка L в начале в исходном, а затем в обратном порядке.  
Решение: Заполнял список числами с клавиатуры через `std::copy` с `std::back_inserter`, выводил через `std::copy` с `std::ostream_iterator` в прямом и обратном порядке.  
Ключевые методы:** `begin()`, `end()`, `rbegin()`, `rend()`, `std::copy`, `std::back_inserter`

Задача 2 - Обмен половинами между вектором и деком
Дана задача: Добавить в конец вектора первую половину элементов дека, а в начало дека — вторую половину исходных элементов вектора в обратном порядке.  
Решение: Брал первую половину дека → добавлял в конец вектора через `insert`, брал вторую половину вектора через обратные итераторы → добавлял в начало дека через `insert`.  
Ключевые методы: `insert()`, `begin()`, `rbegin()`, арифметика итераторов

Задача 3 - Удаление средних элементов

Задача 4 - Арифметическая прогрессия
Дана задача: Вывести N первых членов арифметической прогрессии с первым элементом A и разностью D.

Задача 5 - Вставка нуля перед совпадающим элементом
Дана задача: Добавить нулевой элемент перед последним элементом в первой половине вектора, совпадающим с каким-либо элементом из второй половины.  
Решение: Искал в первой половине вектора элемент, который есть во второй половине через `std::find`, перед первым таким элементом вставлял 0 через `insert`.  
Ключевые методы: `std::find`, `insert()`, арифметика итераторов

Задача 6 - Циклические сдвиги списка
Дана задача: Скопировать первые 5 элементов в конец с циклическим сдвигом вправо на K, последние 5 элементов в начало с циклическим сдвигом влево на K.  
Решение: Использовал `std::rotate_copy` и `std::rotate` для сдвигов, временные векторы для хранения промежуточных результатов, `advance` для перемещения итераторов.  
Ключевые методы: `std::rotate`, `std::rotate_copy`, `advance()`, `insert()`

Задача 7 - Сортировка и добавление половины
Дана задача: Добавить в конец вектора первую половину элементов отсортированного по возрастанию варианта исходного вектора.  
Решение: Сортировал вектор по возрастанию через `std::partial_sort_copy`, брал первую половину отсортированного вектора, добавлял эту половину в конец исходного вектора через `insert`.  
Ключевые методы: `std::partial_sort_copy`, `insert()`

Задача 8 - Объединение слов из списка
Дана задача: Получить дек со строковыми элементами, каждый из которых строится по паре соседних элементов исходного списка.  
Решение: Брал пары соседних слов из списка, из левого слова брал первую букву, из правого - последнюю, объединял их в новое слово, добавлял в дек.  
Ключевые методы: Итераторы списка, `substr()`, `push_back()`

Задача 10 - Группировка по последней цифре
Дана задача: Выполнить группировку элементов вектора по последней цифре, представить результат в виде мультиотображения.  
Решение: Группировал числа вектора по последней цифре через `abs(num) % 10`, создавал мультиотображение где ключ - последняя цифра, значение - число, сохранял исходный порядок.  
Ключевые методы: `std::multimap`, `insert()`, `make_pair`
